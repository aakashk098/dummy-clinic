# Willow & Care — Static Clinic Demo

A professional, dependency-light static website concept for a small-town family clinic + health shop.

## Files
- `index.html` — page structure/content
- `style.css` — responsive design system and visuals
- `script.js` — mobile navigation + demo form behavior

## Run
Double-click `index.html`, or serve the folder with any simple local web server.

## Before using for a real clinic
Replace the demo name, address, phone, hours, service claims, and form handling. Add the clinic's real branding, credentials, privacy notice, accessibility checks, and verified medical information.
